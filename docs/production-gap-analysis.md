## 핵심 결론

1. **백엔드·DB·인증·결제는 0에서 새로 구축**해야 한다. 다만 비즈니스 규칙은 데모에 이미 명세 수준으로 존재하므로 "설계"보다 "이관·강제"가 핵심이다.
2. **프런트엔드는 원본 소스가 없어 재구현이 필요**하다. 데모 `index.html`을 시각 기준으로 삼아 Next.js로 화면을 옮기되, 순서는 핵심 사용자 흐름(가입→자격증→챌린지→결제→학습→인증→포인트) 우선.
3. 외부 계약이 필요한 항목(토스 실가맹, 소셜 로그인 앱 등록, 고용24 키, 쿠폰 공급사, AWS 계정)은 **어댑터 + 테스트 모드**로 먼저 완성하고 키만 넣으면 전환되도록 한다.
