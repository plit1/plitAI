## 테스트 중 발견·수정한 결함
1. 600분 초과 세션의 INVALID 처리가 트랜잭션 롤백으로 사라져 세션이 영구 RUNNING → 트랜잭션 밖에서 확정하도록 수정
2. 웹 `useApi` 첫 렌더에서 `loading=false·data=null` 구간 → `/my/points` 직접 진입 시 화면 오류 → 파생 로딩 상태로 수정
3. 테스트에서 레이트 리밋이 가입을 막음 → 한도를 런타임 평가로 바꾸고 레이트 리밋 전용 테스트 추가
